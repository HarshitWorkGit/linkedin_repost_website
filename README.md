# Synergy AI

A small static website that will later show reposted social posts as cards. This repository is separate from the LinkedIn repost automation project and does not depend on it.

The current site is a landing page with a header and a **Latest Posts** section of sample cards. There is no backend, database, or third-party integration yet.

## Install

No dependencies. The site is plain HTML and CSS.

## Run locally

From this folder, open `index.html` in a browser, or serve the folder with any static file server. For example, with Python:

```bash
python -m http.server 5173
```

Then visit [http://localhost:5173](http://localhost:5173).
